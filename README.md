# Still Here

One hopeful quote a day. Public-domain words only.

- Everyone sees the same quote on the same day. The list is walked in a fixed shuffled order, so nothing repeats until every quote has been shown.
- Day palette ("Morning fog") from 6am to 7pm local time, night palette ("Night candle") the rest of the time. Add `?theme=day` or `?theme=night` to the URL to force one.
- The background drifts very slowly and holds still if the device asks for reduced motion.

## Adding quotes

Edit `quotes.js`. Each quote needs the text, the author, the source work and year, and a link to the original text. If any of those is missing, it doesn't go in.
